# Exam Project

სასწავლო HTML5 პროექტი Git და GitHub ვერსიის კონტროლის სამი ეტაპისთვის.

## ეტაპები
1. Git რეპოზიტორის შექმნა და პირველი commit.
2. `feature-header` განშტოებაში header-ის დამატება და main-ში merge.
3. `nav-feature` და `nav-alt` განშტოებებში ერთსა და იმავე ნავიგაციაზე ცვლილებები, merge conflict-ის აღმოჩენა და მოგვარება.

## ფაილები
- `index.html` — HTML5 გვერდი.

## შედეგი
საბოლოო main განშტოებაში გაერთიანებულია ნავიგაციის ორივე ბმული: მთავარი და ჩვენ შესახებ.
